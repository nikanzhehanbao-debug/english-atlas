只扩充已开放的 L01/L04；不是 M2，不解锁其他十课。原基础路径的十道题、ID、80%通过线、最好成绩和教学卡全部保留。`/lesson/:id/challenge` 是可选路径，每课六道封闭题加一项自主表达，记录与基础课完全分开。

## 内容与判分审查

下表记录本轮逐项文字/答案/干扰项的工程内容核查，供英语审校者在 PR 中复核；不声称已经过真人教师或用户的英语审校。

| 题目       | 任务与唯一封闭目标     | 判分边界与解释                                                                              |
| ---------- | ---------------------- | ------------------------------------------------------------------------------------------- |
| L01 CH1 Q1 | b d p q → B D P Q      | 按序、区分大小写；方向相似不代表同一字母                                                    |
| L01 CH1 Q2 | 识别小写 L → l         | 大写 I、小写 i 均不等于 l；用题目指定大小写避免歧义                                         |

| L01 CH1 Q4 | G J Q → g j q          | 大小写映射与顺序；不是音素考试                                                              |

| L01 CH1 Q6 | Ben → ben              | 指定为字形练习；同时说明真实人名通常首字母大写                                              |
| L01 CH1 Q7 | 自选英文名与大小写拼写 | 自由表达，示例不是唯一答案；保存原文和显式自评，不自动判错                                  |

封闭题沿用可测试的 normalize/grade，支持弯引号、两端空白、空格归一化及可选句末句号；只有字形题严格区分大小写。开放题 `correct=null`，完全排除封闭正确率，永不展示口语自动通过或 AI 评分。尚未点“检查/保存”的草稿不持久保存；保存过的答案和反馈可恢复。

## 听读边界

提供单独“不计分”听读自检，播放静态合成示范并支持展开参考文本和自行跟读提示。无音频时仍可看文本，不生成答错记录。阶段 A 的音频尚待人工实听，因此本阶段**不增加自动判分的字母听辨、听后选择或最小对立对题**。这是明确待验收项，而非把 TTS 或模拟播放当成可靠听力测验。没有录音、识别、上传或发音评分。

## 持久化与兼容

数据库名仍为 `english-atlas-m1`。schemaVersion 从 1 升至 2，upgrade 仅在旧版本创建新增表 `challengeAttempts`；已有四表不删除、不重写。

- 旧 settings、lessonProgress、exerciseAttempts、seenItems 原样保留；基础判题函数、课程内容和基础仓库动作保持行为不变。
- 挑战记录用独立 attemptId、contentVersion=1 和固定 questionIds，保存答案、时间、自评和完成状态。挑战只写新增表，不增加基础课程次数、不改最好成绩、不将内容标成掌握。
- 并发创建、重复答案和结算都有事务与稳定 ID 防重；提交失败保留页面输入，允许重试；共享快照刷新完成后再展示新状态，避免出现尚在保存的首题。
- 旧版本标签页可能阻止 IndexedDB 升级，此时显示关闭其他英语图鉴页面后重试的提示，不删库。升级被阻塞后迟到的连接会关闭；新版本连接遇到未来升级会响应 versionchange 主动关闭。
- 降回仍显式请求 DB version 1 的旧应用会遇到 VersionError。因此**不要在保留数据时将新版本回滚到原 schema1 构建**；如需回滚 UI，应保留本阶段兼容的 v2 仓库层。没有用清库来解决版本回退。
- 手机、平板及不同 origin 的数据仍各自独立；没有引入导出、云同步或复习算法。

## 验证方式

新增内容/仓库/界面测试覆盖：标准答案和干扰项、真实 v1 数据库 fixture 升级、四表逐字保留、旧尝试续答与历史成绩统计、升级阻塞后重试、并发防重、开放表达不计分、无声文本替代、保存失败重试、两课七项挑战全部完成与重挂恢复。原基础路径和语音测试继续执行。

浏览器 QA 使用隔离 Chromium 和自己创建的 v1 测试数据库，不读取、重置或上传用户数据。实际 Android 的物理输出、语音自然度、触控和关闭浏览器再打开的恢复仍留给用户验收。待 PR 审查通过后再决定发布；本轮不合并、不部署。
