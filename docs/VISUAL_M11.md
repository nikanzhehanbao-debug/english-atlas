# M1.1 B · 田野图鉴视觉规范

先设计再实现：本阶段在修改组件和 CSS 前创建 `visual-direction.svg`，用首页封面、区域地图、收藏卡三张示意确定统一方向。本轮用原创矢量插画、档案编号、路线节点和自创植物徽章传达温和冒险感；不复刻官方角色、精灵球、商标、道馆徽章或特有界面。

## 构图与素材

- 封面：带书脊与压印编号的奶油色田野手册；天蓝插画窗、草地、山丘和自创学习伙伴“小苔”，明确的今日继续学习入口。所有学习按钮有独立文字区，手机插画排在文字之后。
- 地图：四片可视化区域（林地、河湾、山谷、营地），岛屿缩略插画、贯穿节点的路线与档案式单元索引。仅 L01/L04 是可点击节点；其余课程锁定。徽章只显示真实测验通过，不增加虚假成长值。
- 收藏卡：固定条目编号、档案页签、发现章、双层纸边；保留“已接触”而非“已掌握”。仅真实接触内容出现。
- 原创矢量资源由本项目创作，按 CC0-1.0 提供（本阶段新增 SVG 与 Guide/FieldArt 图形）；不含第三方图片、字体和音效。源码可审阅。

## 色彩与层级

沿用项目色板：奶油白 #FFF9ED、天空蓝 #84CBE7、青草绿 #99CB9C、珊瑚红 #F38D81、徽章黄 #F4D36E、深海蓝 #293E58。辅助深绿与低对比背景纹理仅装饰；正文保持深色。英文示例独立行，主要操作中文；编号为小型等宽字体。圆润外轮廓搭配手册方页签，避免所有区域都成为相同白卡片。

## 响应式与访问

360/390/430px 手机单列、底部导航、安全区与至少44px按钮；插画不覆盖按钮，地图单列。800/1024px 平板侧栏，地图根据可用宽度变为双列。内容宽度受限，收藏卡自适应。可见焦点、文字状态及减少动画偏好保留；不依赖颜色表达锁定/通过。学习页继续以单任务为主，不加动画延迟或战斗机制。

本阶段不改课程与 IndexedDB，不自动部署；通过独立 PR 评审。布局由真实 Chromium 的五个指定视口检查，Android 的真实触控、系统语音和软键盘仍待用户验收。

## 实际验证

本阶段 lint、38 项测试、build 通过。隔离 Chromium 在 360/390/430/800/1024px × 七个页面入口共 35 项检查均无横向溢出，未捕获页面脚本错误。实际截图位于 `docs/screenshots`：home-390.png、learn-800.png、atlas-360.png。截图中七个接触条目来自隔离浏览器内按教学卡实际操作生成的测试记录，不是用户数据或应用预置数据。

已查看首页、地图与图鉴截图，确认插画与文本分区、四区节点和卡片层级。上述是桌面 Chromium 指定视口验证，不能替代 Android 真机触控、软键盘、字体和系统语音验收。
